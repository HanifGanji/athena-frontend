# Vendored project skills

These skills are committed to the frontend repository so all developers and
coding agents use the same design guidance. `AGENTS.md` defines when each skill
must be selected.

`git/` is the project-authored contribution workflow. It requires pull requests,
squash merges, and source-branch cleanup.
